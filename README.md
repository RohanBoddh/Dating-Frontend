# Dating ❤️ — Frontend

Romantic date proposal interactive web application.

## Features
- 🐾 Playful "No" Runaway Button (cannot be clicked)
- 🍕 Food Vibe Selection Card (Pizza, Sushi, Burgers, Pasta, Tacos, Ramen)
- 📅 Date Picker with Real Name & Gmail verification
- 💖 Celebration Page with "I Love You 3000 ❤️"
- 📱 100% Mobile & Multi-Device Responsive (iOS & Android safe-areas)
- 🎵 Romantic Background Audio with floating toggle
- 🌸 Floating Hearts & Confetti Particles
